# Technical Inspection

Rough order at competition `#verify`:

1. Pre-inspection / documentation check
2. Accumulator inspection (EV)
3. Electrical inspection (EV) — insulation monitoring, shutdown circuit demo, TSAL, IMD test
4. Mechanical inspection — frame, harness, fasteners, driver fit, egress
5. Tilt table
6. Noise (IC) / rain test (EV) — no IMD trip under water spray
7. Brake test — lock all four wheels
8. Ready for dynamics

## Our pre-tech checklist

- [ ] Every driver fits and can egress in ≤ 5 s
- [ ] All critical fasteners grade 8.8+ with positive locking
- [ ] All required labels and stickers on
- [ ] Rain test done at home with a hose
- [ ] Brake test done at home on the same surface type
- [ ] Spare parts list printed
