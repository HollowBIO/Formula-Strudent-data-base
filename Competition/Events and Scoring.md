# Events and Scoring

FSAE (US) maximum points `#verify` — Formula Student events use slightly different splits.

| Event | Type | Max points |
|---|---|---|
| Business / presentation | static | 75 |
| Cost and manufacturing | static | 100 |
| Engineering design | static | 150 |
| Acceleration (75 m) | dynamic | 100 |
| Skidpad | dynamic | 75 |
| Autocross | dynamic | 125 |
| Endurance (~22 km, driver change) | dynamic | 275 |
| Efficiency | dynamic | 100 |
| **Total** | | **1000** |

## What this means for the design

> [!important] Finishing endurance is worth more than anything else
> Endurance + efficiency = 375 points, and both are zero if the car DNFs. A reliable, slower car routinely beats a fast fragile one. Budget testing time accordingly — target **≥ 500 km / 30 h of driving before competition** is a common rule of thumb for top teams.

- Statics (325 pts) are mostly "paperwork + understanding". Design judges ask *why* and *how did you validate it*. Every [[Decisions|decision]] note is future design-event material.
- Scoring formulas are relative to the fastest car — use [[Points Estimate]] to see where a second is worth the most.
