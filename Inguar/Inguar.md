# Inguar

Meeting notes. One note per meeting, named `YYYY-MM-DD Topic`. Make one by creating a note in this folder and running *Templates: Insert template* → **Meeting**.

## All meetings

```dataview
LIST FROM "Inguar" WHERE file.name != "Inguar" SORT file.name DESC
```

> [!note] The list above needs the Dataview community plugin. Without it, use the folder in the file explorer.
